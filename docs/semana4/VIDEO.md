# Video MVP — link editable

## URL que va en Apex / MVPFunctional

```
https://www.youtube.com/watch?v=VIDEO_URL
```

1. Suban el video a **YouTube → Sin listar**.
2. Copien el enlace (o solo el ID) y reemplacen `VIDEO_URL` en [`MVPFunctional.md`](./MVPFunctional.md) (sección **Video público** y tabla **Evidencia**).
3. Si después editan: YouTube Studio → el mismo video → **Reemplazar archivo**. El link no cambia.
